# Migration to 0.5 covers, plates and platform fit

Nothing in an existing project stops working. Every addition is opt-in and off
by default.

## Existing workspaces

`workflow-state.json` records the component versions that created it, so a
workspace started on 0.4 refuses to resume on 0.5 and says so. Finish open edits
on 0.4, or recreate the workspace; artifacts themselves are unchanged apart from
the additions below, which are all optional fields.

## Project config

Two new optional keys, both defaulting to the previous behaviour:

```yaml
image_generation_policy: none     # none | optional | required
target_platforms: []              # e.g. [reels]
```

`music_policy` and `sfx_policy` already existed and were inert. They are now
enforced: with `none` (the default) an EDL that mixes a bed or places an effect
is refused before rendering, and with `required` an EDL without one fails. If
you had set either to `optional` or `required` as documentation, it now has an
effect — set it back to `none` if you did not mean it.

`image_generation_policy: optional` is what lets `image plate` run without
`--allow-cloud-image`. `target_platforms` makes `qa` and `deliver` check those
destinations without repeating `--platform`.

## Brand QA is stricter on purpose

Render manifests now record which caption features the renderer actually
applied, and brand QA compares the contract against that evidence. If your
contract sets `highlight_active_word: true` and you render with Remotion, the
highlight is now genuinely drawn — previously it was silently dropped. A
contract that asks for it while the caption track has no word timings now fails
QA instead of passing with flat captions. Re-transcribe or regenerate captions
so word timings exist, or set `highlight_active_word: false`.

## Audio and framing

`audio_bed` and `sound_effects` are new optional EDL fields. Existing EDLs have
neither and render exactly as before. `--reframe speaker` no longer logs
"not implemented": it now analyses the range, which costs one extra decode pass
over the clip. `--reframe face` is unchanged.

## Delivery

`--poster` is unchanged: a raw frame grab. `--cover` is new and requires a
composed cover from `social-video-agent cover`. `--publish` requires a
`publish.json` you wrote.
